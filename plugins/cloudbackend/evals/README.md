# Evals

The cases `claude plugin eval` grades (Claude Code 2.1.269 or later): one folder per case, `<skill>-<id>/`, generated by
the repository's `scripts/gen-evals.mjs` from each skill's own evals and never edited here. Each holds `prompt.md`
(the prompt, verbatim) and `graders/`: `assertions.md`, an `llm` grader over the run's trace listing the assertions;
`uses-skill.md`, a `tool_used` grader for `Skill` on the cases whose prompt names the skill (an indicator, not scored);
and on two cases a `baseline` grader against a reference transcript. `results/` (ignored by git) is where a run writes
its report. The release pipeline runs the suite with pinned models and skips it when the skills are unchanged since
the last release.
