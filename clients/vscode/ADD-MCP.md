# VS Code: add the servers

Generated by scripts/gen-clients.mjs for plugin version 2026.1104.0; edit the generator, not this file.

Unzip the plugin, run `sh <plugin-dir>/scripts/ensure-build-venv.sh <plugin-dir>/.data` once (the build server's Python environment; needs Python 3.12 or uv), then one
command per server with `<plugin-dir>` replaced by the unzipped folder (user settings; Copilot agent mode lists the tools):

```bash
code --add-mcp '{"name":"cloudbackend-docs","command":"node","args":["<plugin-dir>/servers/docs/index.mjs"]}'
code --add-mcp '{"name":"cloudbackend-build","command":"<plugin-dir>/.data/venv/bin/python","args":["-m","cbemcp_build"],"env":{"PYTHONPATH":"<plugin-dir>/servers/build/src"}}'
```

Or copy `mcp.json` next to this file to the workspace's `.vscode/mcp.json` and replace `<plugin-dir>` there.
