# VS Code: add the servers

Generated by scripts/gen-clients.mjs for plugin version 2026.1104.0; edit the generator, not this file.

Unzip the plugin, then one command per server with `<plugin-dir>` replaced by the unzipped folder (user settings; Copilot
agent mode lists the tools). Both servers need Node 22 and nothing else:

```bash
code --add-mcp '{"name":"cloudbackend-docs","command":"node","args":["<plugin-dir>/servers/docs/index.mjs"]}'
code --add-mcp '{"name":"cloudbackend-build","command":"node","args":["<plugin-dir>/servers/build/index.mjs"]}'
```

Or copy `mcp.json` next to this file to the workspace's `.vscode/mcp.json` and replace `<plugin-dir>` there.
