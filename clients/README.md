# The plugin's servers for other clients

Generated by scripts/gen-clients.mjs for plugin version 2026.1104.0; edit the generator, not this file.

The documentation and build servers run on your computer, from the unzipped plugin (`cloudbackend-2026.1104.0.zip` from the marketplace,
or a checkout of this repository: `plugins/cloudbackend/`). Every file here names that folder as `<plugin-dir>`; replace it.
Both servers need Node 22 and nothing else; the documentation server reads the developer portal and needs no sign-in,
the build server works on the files in the request.

| Client | File | How |
| --- | --- | --- |
| Cursor | `cursor/mcp.json` | as `.cursor/mcp.json` in the project, or merged into `~/.cursor/mcp.json` |
| VS Code | `vscode/mcp.json`, `vscode/ADD-MCP.md` | `code --add-mcp` one-liners, or the file as `.vscode/mcp.json` |
| Codex CLI | `codex/config.toml` | append to `~/.codex/config.toml` |
| Gemini CLI | `gemini/settings.json` | merge into `~/.gemini/settings.json` |

| Server | Runs | Gives |
| --- | --- | --- |
| `cloudbackend-docs` | `node <plugin-dir>/servers/docs/index.mjs` | documentation lookups, read-only: topics, REST operation cards with XML bodies, SDK method cards, the nine XIOS/3 reference lookups (components, operations, functions, methods, events, actions, concepts, lists, icons); reads the developer portal, needs no sign-in |
| `cloudbackend-build` | `node <plugin-dir>/servers/build/index.mjs` | build tools for a XIOS/3 package, no tenant needed: lint_project (the tenant grammar G01-G20 before an upload; schema validation happens at upload) and benchmark_project (the measured block of a benchmark report) |

The deploy connector is CloudBackend's and per tenant (`https://mcp.cloudbackend.com/mcp/<tenant>`): `<plugin-dir>/scripts/connect-deploy.sh <tenant> --print`
prints it in each client's shape. The skills themselves are Claude's; for another agent, point it at
`<plugin-dir>/skills/<name>/SKILL.md` (the open Agent Skills layout).
